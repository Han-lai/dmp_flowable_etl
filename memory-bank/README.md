# Memory Bank - DMP Flowable 專案

此目錄包含專案的累積知識與進度追蹤，供 AI 助手自動參考與更新。

## 目錄結構

```
memory-bank/
├── README.md           # 本說明文件
├── projectbrief.md     # 專案概述與目標
├── productContext.md   # 業務背景與資料來源
├── systemPatterns.md   # 架構模式與技術決策
├── techContext.md      # 技術堆疊與環境設定
├── activeContext.md    # 當前進行中的工作
└── progress.md         # 專案進度與里程碑
```

## 自動更新規則

AI 助手在每次對話結束時，應自動更新以下檔案：
1. `activeContext.md` - 當前工作狀態
2. `progress.md` - 完成的里程碑
