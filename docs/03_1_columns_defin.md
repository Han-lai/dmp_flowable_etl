欄位定義說明（指標表格 Columns Definition）

| 欄位                               | 類型                   | 說明                                                                                                                                     |
| -------------------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Vx / Plant / Factory / Line**  | Text                 | 顯示幕前篩選條件結果，依使用者選擇之流程區域（Vx）、廠別（Plant）、製造廠區（Factory）、線別（Line）組合呈現                                                                        |
| **Item**                         | Text                 | 任務狀態項目，固定六種值，不可新增或調整順序：<br/>- Total Task<br/>- Todo<br/>- Doing<br/>- Done<br/>- Doing + Done<br/>- Todo + Doing (Acc) (採 7 天滑動視窗)                 |
| **Total**                        | Numeric + Percentage | 系統累計至今的所有任務數（Task Qty），以及該狀態佔 **Total Task** 的比例 (%)                                                                                   |
| **Month**<br/>`pattern: MMM`     | Numeric + Percentage | 計算篩選月份（自然月 1 號至月底）內的所有任務數（Task Qty），以及該狀態佔該月份 **Total Task** 的比例 (%)                                                                   |
| **W44**<br/>`pattern: W${x}`     | Numeric + Percentage | 根據篩選月份推算出該月份對應的**最大週別 Wx**，並計算該週內的所有任務數與佔比。<br/><br/>- 若該週尚未結束（例如僅有 3 天資料），則僅統計目前已發生的日期<br/>- 該週數值會在週結束後「結算並固定」                        |
| **W43**<br/>`pattern: W(${x}-1)` | Numeric + Percentage | 依據 **Wx** 往前推一週，計算上一週（完整 Mon ~ Sun）的所有任務數與佔比                                                                                           |
| **W42**<br/>`pattern: W(${x}-2)` | Numeric + Percentage | 依據 **Wx-1** 再往前推一週，計算前兩週（完整 Mon ~ Sun）的所有任務數與佔比                                                                                        |
| **Dn-1 ~ Dn-7**                  | Numeric + Percentage | 依據基準日逐日往前推算的日級指標：<br/><br/>- Dn-1：基準日（當天）<br/>- Dn-2：基準日 - 1<br/>- …<br/>- Dn-7：基準日 - 6<br/><br/>**累積比率 (Acc Rate) 修正**：<br/>每一日皆計算該日的 Qty 佔 **7 天滑動總量 (Total Task Rolling 7D)** 的比例 (%)。這解決了週末因單日任務量低導致比例暴增的問題。 |

# 📊 邏輯修正與優化分水嶺 (2026-02-04)

### 已修正項目
1.  **Vx 歸屬邏輯**：優先級調整依序為 `MO Number` -> `Task Definition Key` (V1/V2/V3)。
2.  **時點快照 (Point-in-Time)**：狀態判定 (Todo/Doing/Done) 改為依據 `snapshot_date` 與任務時間戳記的比對，而非當前狀態。
3.  **累積在途量 (Acc)**：定義修正為 7 天滑動視窗 (D 至 D-6 有活動且 D 當下未完成)。

### ⚠️ 已知差異 (Known Discrepancies)
*   **WJ2 NBU E5 (V3) DONE Count**:
    *   **2025-12-30**: 系統值 196 vs 用戶值 194 (差異 +2)。
    *   **2025-12-31**: 系統值 197 vs 用戶值 196 (差異 +1)。
    *   **原因分析**: 差異來自 `V3_5_4_1_1` (Fixture Recycle Plan) 與 `V3_5_4_1_3` (Auxiliary Material Recycle Plan) 任務。
    *   **狀態**: 用戶指示暫不排除這些任務，保留此差異並暫停調查 (2026-02-04)。

針對 L5 指標數據不一致問題，於 2026-02-04 完成以下核心邏輯調整，並同步更新至 Gold 層計算引擎。

### 1. Vx 歸屬優先級 (Vx Attribution Priority)
*   **變更前**：優先套用「特殊工單號碼」規則（如 315% 歸為 V1），導致定義為 V3 的任務被誤植。
*   **變更後**：**優先判斷 TaskDefinitionKey 前綴**。
    *   若任務定義明確標示為 V1/V2/V3，則直接歸屬。
    *   僅在任務定義無法判定時，才套用工單號碼（moNumber）的輔助歸屬規則。
*   **目標**：確保跨流程呼叫（如 V1 調用 V3）時，任務能回歸其原始流程定義。

### 2. 時點快照狀態 (Point-in-time Status)
*   **變更前**：使用任務「目前最新狀態」統計歷史數據，導致歷史報表隨時間變動（昨日 Todo 今日看變 Done）。
*   **變更後**：改採 **時點判定邏輯**。
    *   依據 `snapshot_date` 與任務的 `START_TIME_`、`CLAIM_TIME_`、`END_TIME_` 進行動態比對。
    *   **Todo**：`snapshot_date < 認領時間`。
    *   **Doing**：`snapshot_date >= 認領時間` 且 `snapshot_date < 完成時間`。
    *   **Done**：`snapshot_date >= 完成時間`。
*   **目標**：確保歷史數據定格，滿足稽核與趨勢分析需求。

### 3. 累積在途量 (Acc) 滾動邏輯
*   **變更前**：僅計算當日的 (Todo + Doing) 總量。
*   **變更後**：採用 **7 天滑動活動視窗 (Rolling 7-Day Activity)**。
    *   **計算範圍**：[快照日 Dn, Dn-6] 區間內有活動（開始/認領/結束）的任務。
    *   **判定準則**：該範圍內曾活動過，且截至 `snapshot_date` 當日結束時尚未結案（非 Done）的任務總數。
*   **目標**：真實反映「近期一週內產出且積壓中」的實際工作負擔。

### 4. V2 模型大氣候與篩選魯棒性 (V2 Robust Filtering)
針對 Superset 不同情境（Dashboard vs Chart）傳送的時間格式不一問題，實施以下改善：
*   **Triple-OR 篩選邏輯**：在 `params` CTE 中同時比對 `YYYY-MM-DD`、`YYYY-MM-DD 00:00:00.000000` (微秒) 與 ISO 格式。
*   **全字串化比對**：將日期欄位 `toString` 後再與篩選參數比對，徹底排除 ClickHouse 報錯 「Cannot convert string to type Date」。
*   **分母對齊 (Denominator Alignment)**：
    *   **Day**: 使用 7 天滾動總量。
    *   **Week/Month**: 使用整個週期內的加總量。
